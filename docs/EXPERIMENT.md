# 已完成的 Odin 两阶段实验

这是历史实验记录，不包含当前正在进行的 PDA/LVBA 对照结论。
协议原文见 `odin_experiment_protocol.json`，源码快照来源见 `source_snapshot.json`。

## 方案

第一阶段将相机轨迹节点、视觉三维点和雷达局部平面一起优化；第二阶段固定可靠结构，仅精修视觉位姿。
SDK 只用于初始化及此前逐点运动补偿，没有 SDK 绝对/相对位姿残差。
第一相机固定，保留米制点云尺度。

约束可靠性包含多视角、重投影分布、视差与图像覆盖。弱视觉区域不会因强行精修而额外更新位姿。
扫描时刻在邻近相机节点之间使用相机中心线性插值与归一化四元数线性插值。
初始雷达平面关联固定，平面参数参与优化；不联合优化扫描内逐点轨迹、外参或时间偏移。

## 3DGS 对照

相同 1437 张图像、271105 初始点、1257/180 图像划分、种子 2026、默认训练参数、30k 步及 SDK 场景半径。
唯一训练输入变化为相机位姿。后续训练共同使用 K=550 的图像；LVBA 本身使用历史 K≈406.8 图像与匹配，不能混用这两个配置。

| 方法 | PSNR (dB) | SSIM | 高斯数 | 训练时间 (分钟) |
|---|---:|---:|---:|---:|
| SDK 初值 | 26.467 | 0.89437 | 977465 | 34.6 |
| 原 LVBA | 27.975 | 0.91425 | 963609 | 34.8 |
| 联合优化＋固定结构精修 | 28.874 | 0.92923 | 1012581 | 35.0 |

留出图像参与过轨迹和结构优化，不能称为独立采集的测试集。
没有对 joint-only 单独训练 3DGS，因此不能把成像提升拆成两个阶段各自的贡献。

## 几何与计算时间

整体逐对极线误差中位统计从联合阶段 0.2366px 到精修后 0.2349px，P90 从 0.3850px 到 0.3832px。
第二阶段整体提升较小。局部 295→296 帧从 0.580px 改善至 0.485px。

1295→1296 帧只有 38 对验证匹配，精修阶段两相机仅 2/1 条可靠观测，因此保留联合阶段位姿。
该图像对极线误差中位数仍为 10.35px（SDK 为 1.46px），说明局部退化没有全面解决。

优化准备总流程约 6.1 分钟，联合 Ceres 约 144.25 秒，精修约 1.42 秒；不包含特征匹配和逐点运动补偿。
这不是端到端实时 SLAM 指标。

## 解释边界

相对于原版，鲁棒核、视觉约束恢复、轨迹连接方式等多处都发生变化，不能把收益归因于单一改动。
当前版本不自动识别/移除动态物体；多帧一致性和鲁棒核只能抑制部分异常观测。
PDA 增加的点不是独立雷达测量；后续接入时需控制点数、空间分布和权重，不能因稠密就等权放大几何置信度。
