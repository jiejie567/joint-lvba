# 发布构建验证

验证日期：2026-10-27（Asia/Shanghai）。
在与已有实验分开的 Ubuntu 24.04 临时目录验证，不运行或改动已有实验数据。

## 已通过

- 完整 CMake 配置和构建：`lvba_system`、`lvba_io`、`lidar_visual_ba`、`joint_cost_test`。
- CTest：`joint_costs`，1/1 通过。
- 视觉重投影、扫描点到平面、视觉点到平面三种残差的自动微分与有限差分一致。
- 视觉/点云残差在共同的全局刚体变换下保持不变。
- 发布版求解函数与实验快照一致；残差结构体只移至共用头文件，未改数学表达。

记录的雅可比相对误差：

```text
1.28619e-08
1.52417e-09
1.34402e-10
PASS Jacobians and global-gauge invariance
```

构建环境包括 CMake 3.31.8、Ceres 2.1.0、Eigen 3.4.0、OpenCV 4.10.0、SQLite 3.53.4、ROS 1 兼容运行时，以及已有 Coco-LIC 运行时中的 Sophus 头文件。
构建通过不等于在任意新数据集上验证了效果。本次上传没有重跑完整 Odin 优化或 3DGS 训练，也不包含未完成的 PDA 对照结果。

## 初值可复现性

发布核查时，用历史 IMU 位姿文件与配置外参重新生成的相机初值，相对原实验冻结的 SDK 相机文件有最大约 5.21mm 的平移分量差。
这说明不能把不同历史导出的初值当成逐值等价；没有在本次源码发布中改写、替换或重新运行那些初值。
原始数据和轨迹不随仓库分发，复现时应另行保留同一份冻结输入。
